# Customer Registration Module

This Next.js project demonstrates the customer registration experience scaffold. The initial
turn seeds the application with a marketing view that surfaces the Sample Gold Health Plan and
exposes matching JSON-LD structured data so search engines and downstream consumers can index the
offering.

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) to view the plan page and inspect the
embedded `application/ld+json` script for the health insurance plan metadata.
